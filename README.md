# 📚 Sistema de Gerenciamento de Notas Escolares

Projeto desenvolvido em Python como parte das atividades do curso técnico em **Desenvolvimento de Sistemas**. O objetivo é automatizar o fluxo acadêmico escolar, permitindo o cadastro de múltiplos alunos, o registro de disciplinas com notas bimestrais, o cálculo automático de médias, a verificação de aprovação/recuperação e a emissão de relatórios de desempenho individualizados.

---

## 🚀 Funcionalidades

* **Cadastro de Múltiplos Alunos:** Permite registrar vários estudantes em sequência através de um loop de controle principal.
* **Gerenciamento de Disciplinas:** Associa múltiplas matérias a um mesmo aluno de forma dinâmica.
* **Cálculo Bimestral Automático:** Coleta as notas dos 4 bimestres de cada disciplina e calcula a média final.
* **Avaliação de Desempenho:** Classifica automaticamente o aluno como **Aprovado** (média $\ge 5$) ou em **Recuperação** (média $< 5$).
* **Relatório Final Individualizado:** Exibe um resumo organizado com as matérias e médias de cada aluno ao término de seus cadastros.
